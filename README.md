# Ship Your Site

A simple portfolio template you can publish for free with GitHub Pages. No coding experience needed.

**You'll need:** a laptop and a GitHub account with a verified email.

---

## 1. Copy the template

1. Click **Use this template** → **Create a new repository**.
2. Name it **`your-username.github.io`** (use your actual GitHub username).
3. Keep it **Public** and click **Create repository**.

## 2. Edit it

1. Open **`index.html`** and click the **pencil icon** to edit.
   - Or press **`.`** on your keyboard to open a full editor in your browser.
2. Replace the placeholder text. Every spot to change is marked with an `EDIT` comment.
3. Click **Commit changes** to save.

To change colors, edit the values at the top of **`style.css`**.

**Adding your photo or project screenshots:** click **Add file** → **Upload files** in your repo, upload the image, then follow the `EDIT` comment next to the gray box it replaces.

## 3. Publish with GitHub Pages

1. Go to **Settings** → **Pages**.
2. Under **Branch**, select **main** and **/ (root)**, then click **Save**.
3. After about a minute, your site is live at **`https://your-username.github.io`**.

From now on, every time you commit a change, your site updates automatically (it can take a minute or two).

## Going further

### Customize it with AI

You can use an AI assistant like Claude or GitHub Copilot to restyle or extend your site. Paste in your `index.html` and `style.css` and ask for what you want, for example:

- "Make this look more modern but keep it simple and professional."
- "Add a section for my photo next to my name."
- "Add a dark mode toggle."
- "Make the projects show as cards in a grid."

Then copy the updated code back into your files and commit. Read through the changes before you commit, so you know what's in your site.

> Students can get GitHub Copilot free through the GitHub Student Developer Pack.

### Add analytics

Want to see how many people visit your site? [Umami](https://umami.is) is a free, privacy-friendly analytics tool.

1. Create a free account at [cloud.umami.is](https://cloud.umami.is).
2. Add a website and enter your `your-username.github.io` address.
3. Copy the tracking code it gives you. It looks like this:
   ```html
   <script defer src="https://cloud.umami.is/script.js" data-website-id="your-website-id"></script>
   ```
4. Paste it into `index.html` where it says `OPTIONAL: Analytics`, then commit.

Visits will start showing in your Umami dashboard.

---

## Tips

- **Changes not showing?** Wait a minute, then hard refresh (Ctrl+Shift+R, or Cmd+Shift+R on Mac).
- **Made a mistake?** Every commit is saved. Open the file and click **History** to see earlier versions.
- **Want a custom domain** like `yourname.com`? Search "GitHub Pages custom domain."
